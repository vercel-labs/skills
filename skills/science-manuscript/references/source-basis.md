# Source Basis

Last checked: 2026-05-19.

Use this file to separate stable Science-family submission principles from details that must be
verified on the current target-journal page.

## Source hierarchy

1. Current target-journal author instructions on Science.org or the journal submission system.
2. AAAS/Science editorial policy pages and official author-facing guide materials.
3. Discipline standards for reporting, repositories, ethics, statistics, images, and code.
4. Non-authoritative mirrors of Science templates only when official pages are inaccessible.

## Rules for uncertain details

- Mark word counts, figure counts, article-type names, reference limits, and supplement rules as
  `verified` only after checking the current Science.org page or submission system.
- If official Science.org pages are blocked, provide a provisional manuscript structure and tell
  the user exactly which fields remain unverified.
- Do not quote or copy large blocks from mirrored templates. Use short section labels and
  paraphrased workflow rules.
- Prefer current target-journal instructions over general Science-family author guide material.

## Stable takeaways from accessible AAAS materials

- Science-family papers are selected for broad importance, novelty, and clear communication
  beyond a narrow subfield.
- A complete story matters more than maximizing the amount of material in one paper.
- Figures carry the evidentiary spine; the manuscript should be built around what the data prove.
- Cover letters are part of the submission package and should be concise, concrete, and useful to
  the editor rather than promotional.
- Data, materials, and code availability should be mapped explicitly to the results they support.
