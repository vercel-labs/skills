# Template Contract

Use this reference when building a Science-style manuscript skeleton or auditing a draft against
Science-family submission expectations.

## Intake fields

Capture these fields before formatting:

- Target journal and article type.
- Verified current limits: word count, abstract length, one-sentence summary length, figures,
  tables, references, supplementary material, and file formats.
- Core claim and one-sentence significance for a broad scientific audience.
- Figure/table map: every display item, its claim, and where it is first cited.
- Supplement map: methods, extended data, additional figures/tables, movies, datasets, code,
  protocols, and any files that cannot live in a single supplement document.
- Compliance fields: funding, author contributions, competing interests, ethics approvals,
  clinical/animal/human-subject reporting, data/materials/code availability, and related papers.

## Science-style manuscript parts

Use exact heading labels only after confirming they match the current target-journal instructions.
Legacy Science templates commonly use this flow:

1. `Title:`
2. Author list and affiliations.
3. `One Sentence Summary:` when requested.
4. `Abstract:`
5. `Main Text:`
6. `References and Notes:`
7. `Acknowledgments:`
8. Figure captions beginning with `Fig. 1.`, `Fig. 2.`, etc.
9. Table captions beginning with `Table 1.`, `Table 2.`, etc.
10. `Supplementary Materials:`

## Main-text logic

Build the main text as a compact argument:

- Opening context: why the question matters to non-specialist scientists.
- Scope sentence: what this study tests, builds, measures, or resolves.
- Results sequence: one result block per evidence step, aligned to figures/tables.
- Interpretation: what the result means, bounded by the data.
- Limits: concise and honest when needed; avoid adding unsupported future-work promises.

Do not bury the paper's central advance in the final paragraph. Science readers should understand
the advance from the title, abstract, and early main text.

## Figure and table contract

- Cite every figure and table in order, including supplementary items.
- Each main figure should defend a distinct part of the central claim.
- Captions should identify what is shown and essential experimental context; detailed
  interpretation belongs in the main text unless the target journal requests otherwise.
- Tables should use real table structures in editable documents, not spaces, tabs, or images.
- Supplementary figures/tables should not carry a claim that is absent from the main text.

## Supplementary materials contract

Treat supplementary material as part of the reviewable evidence package:

- Include methods needed for reproducibility when the article type allows or requires offloading.
- Keep supplementary references in the single manuscript reference sequence if the current
  target-journal instructions require it.
- Add captions for supplementary media and large files.
- Cross-check that every supplement item is cited from the main text or supplement text.
- Do not use the supplement to hide weak logic, missing statistics, or essential controls.

## Availability contract

Before finalizing, map every claim-supporting artifact to an access route:

- Data: raw, processed, source data, public datasets, restricted datasets.
- Code: analysis scripts, simulation code, model weights, notebooks, dependencies.
- Materials: plasmids, strains, samples, devices, protocols, reagents, software tools.
- Identifiers: DOI, accession, repository URL, version, embargo, access committee, or request route.

If availability is restricted, state the restriction, controller, access criteria, and what metadata
or representative data can still be public.
