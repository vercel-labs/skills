# Submission Checklist

Use this checklist before calling a Science-family manuscript package ready.

## Blocking issues

Treat these as blockers:

- Target journal or article type is ambiguous.
- Current article-type limits are unverified but the user asks for final formatting.
- Abstract, title, or first paragraph is not understandable to adjacent scientists.
- The central claim is not supported by main figures/tables.
- Essential controls, statistics, or methods live only in unreferenced supplementary material.
- Data, code, or materials availability is vague, missing, or inconsistent with the evidence.
- Required ethics approvals, trial registration, consent, permits, or biosafety statements are absent.
- Reference sequence, figure order, or supplement citations are broken.
- The cover letter hides conflicts, related submissions, preprints, or direct competition.

## Main manuscript

- Title is accurate, specific, and not overloaded with jargon.
- Abstract follows gap, approach, result, consequence.
- One-sentence summary is present only if requested and is short, plain, and result-focused.
- Main text starts with broad context and moves quickly to the research gap.
- Every figure/table is cited in order.
- Claims are bounded by demonstrated evidence.
- Methods detail is placed where the target journal expects it.
- References and notes follow the current target-journal style.
- Acknowledgments include funding, contribution, conflict, and availability elements required by
  the current instructions.

## Figures and tables

- Each figure has a specific evidence role.
- Captions identify what is shown and define non-obvious symbols, statistics, and sample sizes.
- Axis labels, units, legends, colors, and image scale bars are reviewable.
- Image adjustments are consistent and documented when relevant.
- Source data and analysis scripts exist for plotted quantities.
- Tables are editable table objects where the file format permits.

## Supplementary materials

- Supplementary methods are sufficient to reproduce the work.
- Supplementary figures/tables/media are listed and cited.
- Large files, videos, datasets, and code archives have captions or descriptions.
- Supplement references follow the current journal's single-list or separate-list rule.
- Supplement does not contain a result that should be in the main paper.

## Data, code, and materials

- Newly generated data are deposited in suitable repositories when possible.
- Reused public data have stable identifiers and citations.
- Restricted data have a justified restriction and a concrete access process.
- Code has a repository, version, license if applicable, dependency information, and link to data.
- Materials and protocols have identifiers, request routes, or repository records.
- Availability statements match the manuscript, supplement, and repository records.

## Cover letter and metadata

- Cover letter states the main advance and venue fit without hype.
- Suggested reviewers are appropriate and not conflicted.
- Excluded reviewers have concise, defensible reasons.
- Related papers, preprints, conference abstracts, and overlapping submissions are disclosed.
- Author names, affiliations, corresponding author information, ORCID, and funding metadata are
  consistent across files and submission forms.

## Final response pattern

When reporting an audit, lead with:

```text
Blocking issues
- ...

High-value revisions
- ...

Ready-to-paste text
[only for sections with enough information]

Unverified current Science items
- ...
```
