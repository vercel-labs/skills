# Science-Style Manuscript Skeleton

This is a working skeleton, not an official template. Verify current target-journal instructions
before final submission.

```text
Title:
[Concise title that states the advance without unexplained acronyms]

[Authors and affiliations]

One Sentence Summary:
[If required: one compact sentence stating the main result and broad consequence]

Abstract:
[One paragraph: accessible gap, study-specific approach, main results, bounded consequence]

Main Text:
[Brief broad-context opening]

[Specific unresolved gap and scope of this study]

[Result block 1: question, evidence, result, interpretation; cite Fig. 1 or Table 1]

[Result block 2: question, evidence, result, interpretation; cite Fig. 2 or Table 2]

[Result block 3: question, evidence, result, interpretation; cite Fig. 3 or Table 3]

[Synthesis: what the evidence changes, limits, and bounded implications]

References and Notes:
1. [Reference in target-journal style]

Acknowledgments:
Funding:
Author contributions:
Competing interests:
Data and materials availability:
Code availability:

Fig. 1. [Descriptive caption with essential context, sample size/statistics where needed]

Table 1. [Short description of editable table content]

Supplementary Materials:
Materials and Methods
Figures S1-S#
Tables S1-S#
Movies S1-S#
Data files S1-S#
References
```
